# Extralevels 3
This is a metamod plugin for Half-Life 1 mod [Natural Selection](https://github.com/unknownworlds/NS).

Latest community version is version [NS3.3b9](https://github.com/ENSL/NS) (dated 2026.04.05).

## Prerequisites

### Metamod-p

Get the original version from: [Metamod-p v1.21p38](https://github.com/Bots-United/metamod-p)

Or get this actively maintained fork: [Metamod-p v1.21p44](https://github.com/APGRoboCop/metamod-p) (as of 2026.04.05)

## Available commands
In console type "el3".

This gives you the possibility to turn EL3 on/off, reload config and set an EL3 upgrade level.
